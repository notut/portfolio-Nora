📁 Min portefølje:

Velkommen til repositoriet som inneholder min personlige portefølje, der jeg samler prosjekter, 
erfaringer og kompetanse innen utvikling og design.🚀 Målet med porteføljen er å gi et tydelig 
og oversiktlig innblikk i hvem jeg er som utvikler, hva jeg har jobbet med, og hvilke teknologier 
jeg behersker.💡

Porteføljen fungerer som et levende dokument som jevnlig oppdateres med nye prosjekter, forbedringer, 
læring og eksperimenter.📚🔧 Den er bygget for å være:

  Informativ – Beskrive prosjekter, teknologier og problemløsning.
  
  Strukturert – Lett å navigere for både rekrutterere, kollegaer og andre som ønsker innsikt i arbeidet mitt.
  
  Visuell – Presentere prosjekter på en måte som gjør det enkelt å forstå konsept, funksjonalitet og resultat.


🛠️ Innhold i porteføljen

  🧰 En samling av ferdige og pågående prosjekter
  
  💻 Teknologier og verktøy jeg bruker
    
  👤 Kontaktinformasjon og bakgrunn om meg
  

💻⚙️ Teknologi & kjøring av prosjektet

Porteføljen er utviklet i JavaScript ved hjelp av React og Expo 📱.
For å kjøre applikasjonen lokalt via terminalen:
  🔽 Naviger inn i app-mappen: cd app
  ▶️ Start deretter prosjektet med Expo: npx expo start
  
Per nå er porteføljen primært tilpasset web 🌐, men jeg jobber aktivt med å tilpasse den for iOS-simulator også 📲.


🎯 Hensikt

Hensikten med porteføljen er å vise frem både min faglige utvikling og min evne til å bygge løsninger som er 
gjennomtenkte, brukervennlige og teknisk solide.🎨💻 Den skal være et sted hvor jeg både kan dokumentere reisen min 
og invitere andre til å bli kjent med arbeidet mitt.😄👋
